# Kitchen OS · Gourmet Donuts (prototype)

Clickable prototype in English / Español, organized in 4 phases:

1. Operations – Orders, Production, Packing, Kitchen TV (55")
2. Control – Owner dashboard, Closing report, Deliveries
3. Intelligence – Suggested orders, Ingredients, Margins
4. Integration – Store requests, Catering, Registers (POS)

Stores and items from gourmetdonuts.com. Quantities, prices and recipes are examples. Nothing is saved.

Prototype by BI Insights – Leticia Vale da Rosa.
